# RoboDesk 0.1.0 RC1 — evaluation only

Robolution Technologies Ltd. | Science That Makes Sense.

This is a branding and application identity release candidate for authorized support on ordinary Android and Windows test devices. No changes to remote input, connection handling, permissions, or network/security policy are intended. The application ID is com.robolution.robodesk; upstream namespace, native ABI, runtime identity, protocol version, and service names remain unchanged for compatibility. Android installs separately from the previous package; settings do not migrate. Windows is an unsigned portable bundle. Android uses a CI debug signature. Neither is approved for public production distribution. The upstream license and notices remain applicable. The upstream version remains visible separately from the RoboDesk RC label. No private server has been deployed at user request. Validate actual branding, startup, consent, and shutdown on isolated ordinary lab devices. Do not use on operational equipment. Production release requires organization-controlled signing, security review, appropriate server/privacy configuration, and formal device acceptance. Do not claim production status from CI alone.
